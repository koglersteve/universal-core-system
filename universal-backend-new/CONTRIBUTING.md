# Contributing to the Aurelia‑Q Universal Backend

The Aurelia‑Q Universal Backend is the **core system** of the entire Aurelia‑Q ecosystem.  
Changes here affect **every app**, **every user**, and **the Emotional OS itself**.

This document defines the rules, standards, and architecture requirements for contributing.

# 🧠 Core Principles

1. **Stability first** — this backend must never break.
2. **Emotional OS integrity** — OS logic must remain isolated and consistent.
3. **Cross‑App consistency** — all apps must behave identically across the multiverse.
4. **Predictable architecture** — no ad‑hoc folders, no random files.
5. **Zero duplication** — logic lives in one place only.
6. **Strict layering** — backend kernel → cross‑app engine → Emotional OS.
